It's a simple image slider by which a user can slide the images by simply clicking next button and 
see them.

# Features:
1. Can add as many photos as the want
2. One can see the images one by one by next button
3. One can see the previous image

# Key Point:
1. After sliding all the images, it starts over from the very first image

# Languages Used:
1. HTML
2. JavaScript
